# ASME B31 Study Guide

A study companion for the **ASME B31 Code for Pressure Piping**. It is built around ten free PDFs of older B31 editions that US regulations incorporate by reference and that [Public.Resource.Org](sources.md) publishes. Every reading map on this site links straight to the page you need in those PDFs.

!!! warning "Older editions, for learning"
    The free PDFs are 1991 to 2009 editions. They are excellent for learning how the Code works, but rules, tables and paragraph numbers have changed since. For design, fabrication or compliance work, use the edition your regulator or contract names. See [Sources](sources.md) for the current editions.
